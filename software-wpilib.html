Programming Environment

WPILib VS Code

FRC Java / C++ / Python 队伍最先需要安装的编程环境：写代码、建项目、仿真、部署机器人，都从这里开始。

Best for All programming laptops Install timing Before creating robot projects

它有什么用

WPILib 是 FRC 官方生态里最核心的软件包。它把 VS Code、FRC 项目模板、构建工具、仿真、部署命令和常用机器人库整合到一起， 让队伍可以从同一个环境创建 robot project、写 subsystem 和 command、部署到 roboRIO。

对新队伍来说，WPILib VS Code 的价值不是“另一个编辑器”，而是把 FRC 需要的工具链预先配置好， 减少 Gradle、JDK、机器人 IP、部署命令这些初期最容易卡住的设置。

下载前确认

操作系统

选择和电脑系统匹配的 Windows、macOS 或 Linux 安装包。

赛季版本

比赛机器人应使用当前赛季对应的 WPILib 版本，避免和 Driver Station、roboRIO image 不匹配。

安装位置

建议使用默认安装路径，减少队友之间环境差异。

安装步骤

  1. 打开官方安装指南或 GitHub Releases，下载当前赛季的 WPILib installer。
  2. 关闭普通版 VS Code，运行安装器，安装类型选择 Everything 或默认推荐选项。
  3. 安装完成后打开 WPILib VS Code，而不是普通 VS Code。
  4. 用 WPILib 命令面板创建一个新 robot project，语言建议新队伍先选 Java。
  5. 连接 roboRIO 后运行 Deploy Robot Code，确认电脑能成功部署。
