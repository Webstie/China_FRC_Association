REV 设备

REV Hardware Client

用于管理 REV 控制器和电气设备的客户端：更新固件、查看 CAN、配置电机控制器和检查设备状态。

适合使用者 电控组与程序组 常见设备 SPARK MAX / Flex / PDH

它有什么用

REV Hardware Client 是调试 REV 硬件时最常用的工具。你可以通过 USB 连接 SPARK MAX、SPARK Flex、Power Distribution Hub、 Pneumatic Hub 等设备，查看硬件信息、更新固件、设置 CAN ID，并检查连接状态。

在赛季开始、换新电机控制器、或者 CAN 网络出现问题时，先用 REV Hardware Client 把设备固件和 ID 检查一遍，能减少很多部署后才发现的错误。

下载前确认

USB 线

准备一根可靠的数据线。只能充电的 USB 线可能无法识别设备。

设备供电

部分设备需要机器人电源或外部供电才能正常枚举和配置。

固件版本

同一机器人上的同类设备建议保持在同一赛季推荐固件版本。

安装步骤

  1. 打开 REV 官方文档中的 Hardware Client 页面，下载适合系统的安装包。
  2. 安装并启动 REV Hardware Client，按照提示允许必要的驱动或系统权限。
  3. 用 USB 将 REV 设备连接到电脑，等待设备出现在客户端中。
  4. 先更新固件，再设置 CAN ID、motor type、idle mode 等基础配置。
  5. 记录每个设备的 CAN ID，和机器人代码里的常量保持一致。
