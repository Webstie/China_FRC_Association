Driver Station

FRC Game Tools

比赛笔记本必备的 NI 工具包，包含 Driver Station 和 roboRIO 配置工具，用来连接、启用和管理机器人。

Best for Driver station laptop Platform Windows

它有什么用

FRC Game Tools 是驾驶站电脑上的核心软件。Driver Station 负责显示机器人连接状态、电池电压、模式切换、Joystick 输入和 field communication 状态。 没有它，队伍无法像比赛现场一样 enable 机器人，也很难排查通信问题。

它还提供 roboRIO imaging / configuration 相关工具，常用于给 roboRIO 写入赛季 image、设置队号和更新底层系统。

下载前确认

电脑类型

优先安装在正式 Driver Station 笔记本上，开发电脑也可以装一份用于测试。

Windows 环境

FRC Game Tools 主要面向 Windows 驾驶站电脑，比赛现场也通常使用 Windows Driver Station。

队号信息

安装后在 Driver Station 中设置正确 team number，否则无法按 FRC 网络规则连接机器人。

安装步骤

  1. 进入 NI 官方下载页，选择当前赛季的 FRC Game Tools。
  2. 下载在线安装器或离线安装包，按 NI 安装器提示完成安装。
  3. 安装完成后重启电脑，打开 FRC Driver Station。
  4. 在 Setup 页面填写队号，连接机器人 radio 或 USB。
  5. 使用 roboRIO Imaging Tool 检查 roboRIO image 和 team number 是否正确。
