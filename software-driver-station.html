是什么

Driver Station 是驾驶舱

Driver Station（DS）是比赛时驾驶和操作手唯一会看的程序。它跑在 Windows 笔记本上，通过有线网卡和电台（radio）通信，把手柄状态 + Enable 信号转发到 rio。笔记本上其他东西 —— VS Code、各种 dashboard、Phoenix Tuner X —— 都是给程序员看的；DS 是给驾驶员看的。

这一句话决定了你该怎么看待它：比赛中驾驶员不该在菜单里翻来翻去。DS 在 pit 里由程序员一次性配好；上场后它只显示三个状态灯、一个模式、一个电压、一个 console。这就是整个驾驶舱。

DS 是 NI FRC Game Tools 套件的一部分，只在 Windows 上跑。如果还没装，先去装 —— 安装、roboRIO image、填队号都写在 FRC Game Tools 页面。

窗口布局

主窗口长什么样

打开 DS，你看到一个主窗口。顶上是一排标签页；窗口主体是模式选择、Enable / Disable 按钮（F1 是 Enable，Space 是 Disable —— Space 是任何东西看起来不对时一巴掌拍下去的急停键）、三个状态灯、电压、比赛时间，以及最下面滚动的 messages console。

三个状态灯是整个系统的心跳。Communications 绿 = rio 能连上；Robot Code 绿 = 你部署的代码确实在跑；Joysticks 绿 = 至少绑了一个手柄。只要有一个不绿，后面什么都别想动 —— 怪别的东西之前，先从左到右把这三个灯看一遍。

标签页

五个标签页各自的用途

顶上那排标签把 DS 分成五件事。比赛中你只待在 Operation；另外四个在 pit 里配置或排查时才碰。记住哪个标签回答哪个问题，就不会再到处翻找按钮。

标签 用来
Operation 比赛时驾驶。Enable / Disable、模式选择、电压、比赛时间、消息。
Diagnostics 排查问题：ping rio / 电台 / FMS、重启机器人代码、重启 rio。
Setup 队号、Dashboard 选择（Elastic / Shuffleboard / SmartDashboard / LabVIEW）、game data。只设置一次。
USB Devices 物理手柄绑在哪个端口（0 / 1 / 2 / 3）。顺序很重要，你代码里读的是 port 0。把端口锁住。
Power / CAN CAN 利用率、brownout 历史。每次测完瞄一眼。

保命习惯

两个保命习惯，避免大半赛场痛苦

新手队丢掉的比赛，大半归结于两件本可避免的事。两件都不难，但都得在赛前练成条件反射，而不是上了场在最糟糕的时刻才学会。

  1. 01

    在 USB tab 里把手柄绑死端口

    否则，比赛中拔过一次线，所有人的端口编号都会轮换 —— 操作手按的键突然变成驾驶员命令。你的代码是按编号读 port 0、port 1、port 2 的；这些编号一乱，每个 binding 都落到错的摇杆上。在 USB Devices 标签里右键每个设备，把它锁到固定端口。

  2. 02

    任何排查动作之前，先看消息窗口

    底部的 console 里，多数“为什么不工作”的答案早就有了 —— 尤其是 Robot Code 挂掉的时候。你的 stack trace 和 println() 输出都带时间戳打在这里。重启、重新部署、重插线之前，先读最后几行。答案通常已经在屏幕上了。

首次连接

首次连接 —— 队号与 roboRIO 镜像

第一次用时，在你告诉 DS 队号之前，它连不上任何东西。打开 Setup 标签把队号填进去 —— 这一步教会 DS FRC 的网络规则（rio 固定在静态地址 10.TE.AM.2）。设一次就记住了。

rio 要能跑你的代码，先得有本赛季的 image。Game Tools 自带 roboRIO Imaging Tool：用 USB 线把笔记本接到 rio，打开工具，把当年的 image 和你的队号一起写进 rio。image 和你装的 WPILib 必须是同一个赛季 —— 年份对不上，是刚接好线的机器人死活不通信的经典原因。

刷完 image，回到 DS。通过 USB 或机器人电台连上，看 Communications 灯转绿，再到 Robot Code，再到 Joysticks。三个绿，就说明驾驶舱上线，可以 Enable 了。 

First-connection checklist / 首次连接清单

  1. Setup tab → enter team number      填队号
       rio static IP = 10.TE.AM.2
       e.g. team 1234 → 10.12.34.2

  2. roboRIO Imaging Tool (USB cable)    刷 rio 镜像
       write THIS season's image
       image year == WPILib year  ← must match / 必须一致
       also writes the team number

  3. Back in DS, connect (USB / radio)   回 DS 连接
       ● Communications   green
       ● Robot Code       green
       ● Joysticks        green
       → three greens = ready to Enable / 三绿即可 Enable

常见的坑

常见的坑

这些坑踩过一次就不再上当，但每一个都让新手队在场上丢过分。在 pit 里查清楚，别上了场再发现。

  1. 01

    想在 Mac 上跑 DS

    Driver Station 和 FRC Game Tools 的其余部分只在 Windows 上跑。VS Code 和 Gradle 在 macOS 上没问题，但 DS、Game Tools、roboRIO imaging 都不行。给赛场留一台 Windows 笔记本。

  2. 02

    队号填错或没填

    没填队号，DS 就没法套用 FRC 网络规则，也找不到 10.TE.AM.2 上的 rio —— Communications 一直红。在 Setup 标签里设一次，并确认 roboRIO image 里写的是同一个队号。

  3. 03

    image 年份和 WPILib 年份不一致

    roboRIO image 和你装的 WPILib 必须是同一个赛季。年份对不上，是刚接好线的机器人死活不通信的经典原因。用当年的工具重刷一遍。

  4. 04

    手柄端口没锁死

    比赛中拔一个手柄，端口编号就轮换，操作手的键变成驾驶员命令。每场比赛前都在 USB Devices 标签里把每个设备锁到固定端口。

  5. 05

    不读 console 就先重启

    一出问题，驾驶员条件反射地重启 rio 或重新部署。其实 messages 窗口通常已经写明了故障 —— 缺失的 CAN id、stack trace、brownout。先读它，往往根本不用重启。
