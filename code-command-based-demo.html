FRC 代码 · Part 2

第一次让东西动：一颗电机，一个按键 One Motor, One Button — Command-Based + Kraken

本章只做一件极小的事，但用的是每台比赛机器人都在用的写法（Command-Based）。读完你会真正理解“按一个键，电机就转”背后发生了什么，并能自己从零写出来、部署到机器人上。

🎮 按住手柄 A 键 → ⚡ Kraken 电机转 · 松开 → 停
A

先看懂：它是怎么运作的CONCEPTS — 动手前花 5 分钟建立画面感

1大图景：一次按键如何变成电机转动

不要把它想成“按键直接连电机”。中间有一条清晰的链条，每一环都是 Command-Based 的一个零件。记住这条链，等会儿出问题你就知道该查哪一段。

这里有个白送的好处 裸写法里你必须自己写“按住就转、否则就停”。用 Command-Based，“否则停”这句话消失了 —— whileTrue 和命令的 end 动作替你处理了松手。

2四个零件：用一颗电机就能认全

整个框架就四个零件。下面这张图是它们的关系，记住箭头的方向：

3看懂 whileTrue：按住和松开各发生一次

这是最容易搞混的地方。把一次按下沿时间轴走一遍，你会发现“开始”和“结束”各只触发一次，中间什么都不用管。

同一条命令，换个“绑定动词”就是完全不同的按键手感：

绑定方法行为什么时候用
.whileTrue()按住运行，松开立刻停本章用的（按住吸球这类）
.toggleOnTrue()按一下开，再按一下关开关式机构（灯、夹爪锁定）
.onTrue()按一下启动，命令自己跑到结束会自己结束的动作（前进 1 米）
.onFalse()松开时才启动释放类动作
记住这个对比 把“按住运行”改成“按一下切换”，只要把 whileTrue 改成 toggleOnTrue —— 改一个词。裸写法做同样的事得自己加状态变量。
B

动手做：从空项目到电机转HANDS-ON — 跟着做，每一步都有验证点

开始前确认 ① 已装好 WPILib VS Code、FRC Game Tools；② 一颗 Kraken X60 接在机器人上、用 Phoenix Tuner X 确认过它在线；③ 知道它的 CAN ID（本教程假设是 5，你的不同就改代码里的数字）。
1

新建一个 Command-Based 项目

  • VS Code 里按 Ctrl+Shift+P（Mac 是 Cmd+Shift+P），输入并选择 WPILib: Create a new project。
  • Project Type 选 Template → 语言选 java → 模板选 Command Robot Skeleton。
  • 选一个空文件夹、起个项目名、填你的队号，点 Generate Project。
  • VS Code 右下角弹窗点 Yes (Current Window) 打开项目。
为什么是 SkeletonSkeleton（骨架）版只给你最干净的几个文件，没有一堆示例代码要删。我们从空白开始写，更清楚每一行是干嘛的。

✅ 验证：左侧 src/main/java/frc/robot/ 下能看到 Main.java / Robot.java / RobotContainer.java / Constants.java。

2

装上 Phoenix 6 库（Kraken 必需）

Kraken 用 CTRE 的 Phoenix 6 库，新项目默认没有，必须手动加一次，否则后面 TalonFX 会报红、编译不过。

  • 按 Ctrl+Shift+P → WPILib: Manage Vendor Libraries → Install new libraries (online)。
  • 粘贴 CTRE Phoenix 6 的 JSON 链接（去 CTRE 官方文档复制当年的那条，链接每年会变），回车。
  • 装完右下角会提示 build，让它跑一次。
坑vendor 库的版本必须和你的 WPILib 年份一致。链接形如 …/Phoenix6-frcYYYY-latest.json，YYYY 要对上。

✅ 验证：项目里多出 vendordeps/Phoenix6.json。

3

写 Roller 子系统（持有电机）

在 subsystems/ 文件夹上右键 → New File，建 Roller.java，写入下面的内容。这是唯一碰电机的文件。

Roller.javasrc/main/java/frc/robot/subsystems/
package frc.robot.subsystems;

import com.ctre.phoenix6.controls.DutyCycleOut;
import com.ctre.phoenix6.hardware.TalonFX;
import edu.wpi.first.wpilibj2.command.Command;
import edu.wpi.first.wpilibj2.command.SubsystemBase;

public class Roller extends SubsystemBase {

  // Kraken X60 由 TalonFX 控制器驱动，所以类名是 TalonFX。括号里 5 是 CAN ID。
  private final TalonFX motor = new TalonFX(5);

  // 复用同一个控制请求对象（Phoenix 6 推荐做法），用 withOutput() 改输出。
  private final DutyCycleOut request = new DutyCycleOut(0.0);

  // 整个项目唯一命令电机的地方。设成 private：外面只能拿到 Command。
  private void setSpeed(double percent) {
    motor.setControl(request.withOutput(percent));
  }

  // 工厂方法：按住 → 0.6（60%），松开/被打断 → 0（停）。
  public Command runCommand() {
    return startEnd(
      () -> setSpeed(0.6),
      () -> setSpeed(0.0)
    );
  }
}

逐行理解：

  • 那两个 import（phoenix6）—— 来自 Step 2 装的库。如果它们报红，说明库没装好，回去重做 Step 2。
  • new TalonFX(5)—— 在 CAN 总线上找 ID=5 的设备。改成你电机真实的 ID。
  • setSpeed() 是 private—— 外界（RobotContainer）不能直接拨电机，只能通过命令。这就是“硬件只住在一个地方”。
  • startEnd(开始, 结束)—— 造一条命令：被调度时跑一次“开始”，被停/被打断时跑一次“结束”。它自己永远不结束，正好配 whileTrue。
4

在 RobotContainer 里把 A 键绑上

打开 RobotContainer.java，把内容改成下面这样（骨架里已有这个类，你只是填进去）。

RobotContainer.javasrc/main/java/frc/robot/
package frc.robot;

import edu.wpi.first.wpilibj2.command.button.CommandXboxController;
import frc.robot.subsystems.Roller;

public class RobotContainer {

  // 创建子系统 + 手柄（手柄插在 Driver Station 的 0 号 USB 口）。
  private final Roller roller = new Roller();
  private final CommandXboxController driver = new CommandXboxController(0);

  public RobotContainer() {
    configureBindings();
  }

  private void configureBindings() {
    // 核心就这一行：按住 A → 跑 roller 命令；松开 → 自动停。
    driver.a().whileTrue(roller.runCommand());
  }
}

这个文件里没有一个 setControl、没有任何硬件，只有“引用 + 一行接线”。硬件住在 Roller，意图住在这里。

5

确认 Robot.java 里那一行发动机

骨架已经替你写好了，你只需打开 Robot.java 确认它在。漏了它，后面按 A 会毫无反应、还不报错 —— 这是新手第一大坑。

Robot.javasrc/main/java/frc/robot/
  @Override
  public void robotPeriodic() {
    // 整个项目最关键的一行。它每 20ms 驱动一次调度器。
    CommandScheduler.getInstance().run();
  }

✅ 验证：按 Ctrl+Shift+P → WPILib: Build Robot Code，看到 BUILD SUCCESSFUL。报错的话先看是不是 phoenix6 import 的问题。

6

部署到机器人

用 USB 线或电台连上机器人（roboRIO 通电）。

  • 按 Ctrl+Shift+P → WPILib: Deploy Robot Code。
  • 等终端出现部署成功的提示（绿色 BUILD SUCCESSFUL + 一串部署日志）。

✅ 验证：打开 Driver Station，左侧 Robot Code 和 Communications 两个灯变绿。

7

测试！

  • 确认手柄插在电脑上，Driver Station 的 USB Devices 里能看到它在 0 号位。
  • Driver Station 选 Teleoperated 模式，点 Enable。
  • 按住 A 键 → Kraken 转；松开 → 停。
成功了你刚刚用 Command-Based 的完整四件套（Subsystem / Command / Trigger / Scheduler）让第一颗电机动了起来。加第二个机构时，你只要再写一个子系统 + 再加一行 whileTrue。
