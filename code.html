Intro to Code

编程入门 — WPILib 与机器人编程

Getting Started 入门

FRC robots are programmed using WPILib, a robotics library maintained by WPI and the FIRST community. It supports three languages: Java, C++, and Python.

FRC 机器人使用 WPILib 编程。它支持 Java、C++ 和 Python 三种语言。 对于新队伍，我们推荐从 Java 入手 —— 它有最完善的文档和最多的社区资源。

Choosing a Language 选择语言

☕

Java (推荐)

Most popular FRC language. Best documentation, most community examples, fastest to learn.

⚡

C++

Slightly faster runtime. Used by some veteran teams. Steeper learning curve.

🐍

Python (RobotPy)

Easiest syntax. Great for teaching beginners. Smaller community than Java.

Required Software 必备软件

  • WPILib VS Code Pre-configured VS Code with WPILib extensions. Install this first.
  • FRC Game Tools Driver Station + roboRIO imaging tool. Windows-only.
  • REV Hardware Client Firmware updater for SPARK MAX and other REV devices.
  • Phoenix Tuner X Configuration tool for Falcon/Kraken/Pigeon/CANcoder.

Hello, Robot 你的第一段代码

A minimal command-based robot in Java:

public class Robot extends TimedRobot {
  @Override
  public void robotInit() {
    System.out.println("机器人启动！Robot ready.");
  }

  @Override
  public void teleopPeriodic() {
    // Lorem ipsum — drive code goes here
    // 在这里编写遥控期代码
  }
}

Use the RobotContainer class to bind buttons to commands, and create subsystem classes for each mechanism (drivetrain, intake, etc.).

Recommended Learning Path 学习路径

  1. Install WPILib VS Code and run the built-in "Getting Started" example.
  2. Read the WPILib Zero to Robot guide.
  3. Learn the command-based programming framework.
  4. Build a simple tank-drive robot, then add a single subsystem (e.g. intake).
  5. Move on to PID control, motion profiling, and odometry. To be expanded.
