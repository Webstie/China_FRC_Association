Getting Started 入门

FRC robots are programmed with WPILib, a robotics library maintained by WPI and the FIRST community. It supports Java, C++, and Python, and provides templates, simulation tools, drivetrain helpers, and deployment tools.

对新队伍来说，建议从 Java 开始。它的官方文档最完整、示例最多，也最容易在比赛季找到社区答案。

Readable syntax and quick iteration, with a smaller but active community around RobotPy.

First deploy

Hello, Robot 你的第一段代码

Start with a tiny robot program, then move behavior into subsystems and commands as the robot grows. 

public class Robot extends TimedRobot {
  @Override
  public void robotInit() {
    System.out.println("Robot ready");
  }

  @Override
  public void teleopPeriodic() {
    drivetrain.arcadeDrive(
      controller.getLeftY(),
      controller.getRightX()
    );
  }
}

Roadmap

Recommended Learning Path 学习路径

  1. 1

    Install and deploy

    Install WPILib VS Code, create a template project, connect to the roboRIO, and deploy successfully.

  2. 2

    Read Zero to Robot

    Follow the official WPILib Zero to Robot guide and understand robot modes, build files, and vendor libraries.

  3. 3

    Use Command-Based

    Create subsystems for drivetrain, intake, shooter, and elevator, then bind controller buttons to commands.

  4. 4

    Add control loops

    Learn PID, feedforward, sensors, and basic telemetry so mechanisms move predictably.

  5. 5

    Build autonomous

    Move into odometry, PathPlanner or Choreo, AprilTags, and autonomous routine design.
