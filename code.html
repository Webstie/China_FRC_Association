Intro to Code

从 WPILib 环境搭建到 Command-Based 机器人代码，用一条清晰路线帮助中国 FRC 队伍完成第一次可靠部署。

开始学习 必备工具 
package frc.robot;

public class RobotContainer {
  private final DriveSubsystem drive = new DriveSubsystem();
  private final XboxController driver = new XboxController(0);

  public RobotContainer() {
    drive.setDefaultCommand(
      new RunCommand(() -> drive.arcadeDrive(
        -driver.getLeftY(),
        -driver.getRightX()
      ), drive)
    );
  }
}
RIO 已连接 已启用

编程入门

FRC 机器人通常使用 WPILib 编程。它是由 WPI 和 FIRST 社区维护的机器人编程库，支持 Java、C++ 和 Python，并包含项目模板、仿真工具、底盘辅助库和部署命令。

对新队伍来说，建议从 Java 开始。它的官方文档最完整、示例最多，也最容易在比赛季找到社区答案。

第一次部署

你的第一段机器人代码

第一阶段目标不是完美架构，而是能成功部署、能读取手柄输入，并让底盘稳定响应。 

public class Robot extends TimedRobot {
  @Override
  public void robotInit() {
    System.out.println("Robot ready");
  }

  @Override
  public void teleopPeriodic() {
    drivetrain.arcadeDrive(
      controller.getLeftY(),
      controller.getRightX()
    );
  }
}

学习路径

推荐学习路径

  1. 01

    安装并完成部署

    安装 WPILib VS Code，创建模板项目，连接 roboRIO，并完成一次成功部署。

  2. 02

    阅读 Zero to Robot

    跟随 WPILib 官方指南，理解机器人模式、构建文件和 vendor libraries。

  3. 03

    使用 Command-Based

    为底盘、intake、shooter、elevator 等机构创建 subsystem，再把手柄按钮绑定到 command。

  4. 04

    加入控制闭环

    学习 PID、feedforward、传感器和基础 telemetry，让机构运动更稳定可预测。

  5. 05

    构建自动阶段

    继续学习 odometry、PathPlanner 或 Choreo、AprilTags，以及自动路径设计。

核心框架

Command-Based 框架

Command-Based 是 WPILib 推荐的 FRC 代码组织方式。不再把一切塞进一个大循环，而是把机器人拆成持有硬件的 Subsystem 和描述动作的 Command，交给一个统一的 Scheduler 处理冲突，让整体行为可预测。

如果你刚接触 FRC 编程，下面的详解页会从零讲起：项目结构、机器人启动、四个核心部分、写第一个 subsystem 和 command、默认命令、trigger、生命周期、组合，以及新手最常踩的坑。
