Getting Started 入门

WPILib + Command-Based 是 FRC 编程的主线

FRC robots are programmed with WPILib, a robotics library maintained by WPI and the FIRST community. It supports Java, C++, and Python, and includes project templates, simulation tools, drivetrain helpers, and deploy commands.

对新队伍来说，建议从 Java 开始。它的官方文档最完整、示例最多，也最容易在比赛季找到社区答案。

First Deploy

Hello, Robot 你的第一段代码

Start tiny, then move behavior into subsystems and commands.

Your first goal is not a perfect architecture. It is a working deploy, a controller input, and a drivetrain that responds predictably. 

public class Robot extends TimedRobot {
  @Override
  public void robotInit() {
    System.out.println("Robot ready");
  }

  @Override
  public void teleopPeriodic() {
    drivetrain.arcadeDrive(
      controller.getLeftY(),
      controller.getRightX()
    );
  }
}

Recommended Learning Path
学习路径 — build confidence one deploy at a time
5 steps
  1. 01

    Install and deploy

    Install WPILib VS Code, create a template project, connect to the roboRIO, and deploy successfully.

  2. 02

    Read Zero to Robot

    Follow the official WPILib guide and understand robot modes, build files, and vendor libraries.

  3. 03

    Use Command-Based

    Create subsystems for drivetrain, intake, shooter, and elevator, then bind controller buttons to commands.

  4. 04

    Add control loops

    Learn PID, feedforward, sensors, and basic telemetry so mechanisms move predictably.

  5. 05

    Build autonomous

    Move into odometry, PathPlanner or Choreo, AprilTags, and autonomous routine design.
