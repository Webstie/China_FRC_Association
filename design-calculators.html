传动基础学习

使用计算器前，先理解“速度、扭矩、齿比、中心距、张紧、回差”这些概念。FRCDesign 的 Stage 1B 把 power transmission 作为独立训练阶段，建议和本页计算器一起使用。

齿轮基础与啮合

齿轮通过齿面接触传递旋转运动。两个外啮合齿轮转向相反；小齿轮带大齿轮会减速增扭，大齿轮带小齿轮会增速降扭。

常用公式 传动比 = 输出齿数 / 输入齿数 输出转速 = 输入转速 / 传动比 输出扭矩 ≈ 输入扭矩 × 传动比 × 效率 齿轮中心距 = (齿数1 + 齿数2) / (2 × DP)
  • FRC 常见齿轮 DP：20DP、32DP、10DP；DP 越小，齿更大更强。
  • 齿轮啮合需要合适中心距，太紧会发热和磨损，太松会增加回差。
  • 多级齿轮箱的总传动比等于每一级传动比相乘。
  • 高精度机构要尽量减少级数、轴孔间隙和齿轮回差。

皮带传动概念

同步带通过齿形皮带和皮带轮传递运动。和齿轮不同，开口布置的两个皮带轮通常同向旋转，回差很小，适合高速和中低负载机构。

常用公式 传动比 = 输出皮带轮齿数 / 输入皮带轮齿数 皮带节线长度 = pitch × 皮带齿数 FRC 常见 HTD 5mm：长度 = 5mm × 齿数
  • FRC 常用 HTD 5mm 同步带，皮带长度通常是 5mm 的整数倍。
  • 优点是安静、轻、回差小，适合 intake、indexer、shooter、elevator 等。
  • 缺点是抗冲击和高扭矩能力通常弱于链条，需要关注包角和张紧。
  • CAD 中应预留张紧槽、偏心张紧轮或可调中心距。

链条传动概念

链条通过链节和链轮齿啮合传递动力，适合长距离和较高扭矩场景。两个链轮通常同向旋转，传动比由链轮齿数决定。

常用公式 传动比 = 输出链轮齿数 / 输入链轮齿数 链条节线长度 = pitch × 链节数 #25 pitch = 0.25in，#35 pitch = 0.375in
  • #25 链更轻，#35 链更强；高冲击、高扭矩机构更常考虑 #35。
  • 尽量使用偶数链节，减少 half-link，因为 half-link 通常更弱。
  • 链条需要张紧，常见方式包括滑槽、偏心轴承、张紧轮或可调链轮。
  • 链条松弛会导致跳齿和回差，过紧会增加摩擦和轴承负载。

回差、张紧与可控性

回差是机构在真正带动输出前的空行程。它会让 pivot、shooter hood、arm 等高精度机构变得难以控制，所以传动设计不能只看速度和扭矩。

设计判断 低回差优先：齿轮 / 同步带 / 预紧链条 高扭矩优先：齿轮 / 链条 / 大规格皮带 高速低载优先：同步带通常更轻更安静
  • 少一级传动，通常就少一部分间隙和误差来源。
  • 支撑轴承、轴孔配合、键连接或 hex 轴间隙也会贡献回差。
  • 需要闭环控制的位置机构，应在机械端先减少松动，再依靠 PID。
  • 比赛维护时，张紧结构必须容易检查和调整。
FRCDesign: Designing for Controllability

新队员必会：传动比怎么一步步算

1

先判断输入和输出

输入通常是电机或上一级轴，输出是轮子、滚轮、机械臂或升降机构。不要只看图上谁在左谁在右。

2

每一级单独算

齿轮、链轮、皮带轮都可以先用“输出齿数 / 输入齿数”算单级传动比。

3

多级相乘

如果有两级或三级传动，总传动比就是每一级传动比相乘。

4

换算速度和扭矩

减速后输出速度变慢，输出扭矩变大。再乘上效率，才更接近真实机构。

例子：两级减速

第 1 级：12T 小齿轮 → 36T 大齿轮，传动比 = 36 / 12 = 3:1 第 2 级：18T 小齿轮 → 54T 大齿轮，传动比 = 54 / 18 = 3:1 总传动比 = 3 × 3 = 9:1 如果电机转速是 6000 rpm，输出转速约为 6000 / 9 = 667 rpm

读法：这个机构不是“有两组 3:1”，而是总共 9:1。新队员最容易漏掉多级相乘这一步。

结构安装孔设计：把计算结果变成 CAD 孔位

传动计算的最后一步不是截图保存，而是把齿数、中心距、皮带/链条规格写进 CAD 的 layout sketch。孔位设计决定了机构能不能装上、能不能张紧、能不能维修。

齿轮中心距

两个齿轮轴孔之间的距离必须符合齿轮啮合要求。20DP 齿轮常用公式是：

中心距 = (齿数1 + 齿数2) / (2 × DP) 例：12T 和 60T，20DP 中心距 = (12 + 60) / 40 = 1.8 inch

CAD 中应把两个轴孔中心约束到这个距离，并给轴承孔、螺栓孔和板边留足空间。

皮带和链条中心距

皮带/链条不是任意长度都能买到。先用 WCP、ReCalc 或 AMB 算出可用中心距，再回到 CAD 定孔位。

固定中心距：孔位准确，但装配和张紧容错小 滑槽调节：更容易张紧，适合新队员和手工加工 偏心张紧：结构紧凑，但需要更高加工和装配意识

新队伍建议优先使用可调中心距或张紧轮，减少加工误差带来的装不上问题。

孔的类型要分清

CAD 里“孔”不只是圆。轴承孔、螺栓孔、减重孔、滑槽和定位孔的功能完全不同。

  • 轴承孔：决定轴的位置，通常要比普通螺栓孔更谨慎。
  • 螺栓孔：用于固定电机、齿轮箱、支架或板件。
  • 滑槽：用于调整电机、张紧轮或整个轴的位置。
  • 减重孔：不能破坏主要受力路径和边距。

安装孔检查清单

  • 轴孔中心距是否来自计算器或公式，而不是手动拖出来？
  • 链条/皮带是否有张紧方式？调节范围是否足够？
  • 电机、轴承、螺栓头、垫片和工具是否有装配空间？
  • 孔到板边距离是否足够，避免板件开裂或变形？
  • 左右两侧板的孔位是否用同一个 layout sketch 驱动？
课堂建议 先让队员用纸面公式算一遍，再用 ReCalc、AMB 或 WCP 计算器验证。最后把中心距、齿数、皮带/链条规格写回 CAD 的 layout sketch，而不是只把计算结果留在聊天记录里。
