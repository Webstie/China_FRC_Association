CTRE Devices

Phoenix Tuner X

CTRE 硬件的配置与诊断工具，用于 Talon FX、Kraken、CANcoder、Pigeon 等设备的 firmware、CAN ID 和信号检查。

Best for CTRE motor + sensor setup Common devices Talon FX / CANcoder

它有什么用

Phoenix Tuner X 是 CTRE Phoenix 6 生态的配置工具。它可以发现 CAN bus 上的 CTRE 设备，更新 firmware，设置 CAN ID， 查看设备状态和 faults，并帮助你确认电机控制器、编码器和陀螺仪是否正常工作。

如果你的机器人使用 Talon FX、Kraken X60、CANcoder 或 Pigeon，Phoenix Tuner X 应该和 WPILib 一样尽早安装。 这样机械、电控、程序调试时可以快速定位问题来自 wiring、firmware、CAN ID 还是代码。

下载前确认

连接方式

常见方式是通过 roboRIO CAN 网络、CANivore 或 USB-CAN 设备发现硬件。

Phoenix 版本

机器人代码里的 Phoenix library、设备 firmware 和 Tuner X 版本应尽量保持同一赛季范围。

CAN ID 规划

更新前先规划 ID，避免 drivetrain、swerve module 或 sensor 出现重复 CAN ID。

安装步骤

  1. 打开 CTRE 官方 Phoenix Tuner X 文档，根据系统选择安装方式。
  2. 安装完成后启动 Tuner X，连接机器人或 CTRE 设备所在的 CAN 网络。
  3. 扫描设备，确认所有 Talon FX、CANcoder、Pigeon 等设备都能被发现。
  4. 更新 firmware，设置 CAN ID，并清除旧 faults 后重新上电检查。
  5. 把最终 CAN ID 写入机器人代码常量表，提交到队伍代码库。
